# 🚀 PyFerro Showcase & Demo (pyferro-demo)

Для глубокого практического изучения фреймворка, архитектурных паттернов и демонстрации возможностей разработан отдельный обучающий пакет **`pyferro-demo`**.

---

## 🛡️ Безопасность и архитектурная изоляция

В строгих корпоративных и банковских средах недопустимо внедрение учебных таблиц в общую рабочую базу данных.

По этой причине `pyferro-demo`:
- **Полностью изолирован от ядра:** ядро `pyferro` не содержит тестовых или учебных моделей в рантайме.
- **Работает в собственной базе:** по умолчанию создает отдельный файл базы данных `demo.db` (SQLite), гарантируя 100% сохранность и чистоту вашей основной БД.
- **Служит E2E-тестером:** код пакета используется для сквозного тестирования релизов PyFerro в боевых условиях.

---

## ⚡ Быстрый старт

### Установка и запуск в 1 команду:

```bash
# Через pip
pip install pyferro-demo
pyferro-demo run

# Или через pipx без явной установки
pipx run pyferro-demo
```

Сервер запустится на высокопроизводительном Rust-рантайме Granian:
- **Админ-панель:** `http://localhost:8080/pyferro_admin/` (логин: `admin`, пароль: `admin`)
- **JSON-RPC 2.0:** `ws://localhost:8080/wsrpc`
- **Sitemap XML:** `http://localhost:8080/sitemap.xml`

---

## 📂 Что входит в пример: SEO-Форум

В составе `pyferro-demo` реализован полнофункциональный древовидный форум:
1. **Древовидная иерархия разделов:** модели `Topic` и `Message` с рекурсивными родительскими связями (`parent_id`).
2. **Симметричный JSON-RPC 2.0:**
   - Публичные методы: `forum.list_topics`, `forum.get_topic`.
   - Защищенный метод: `forum.create_message` (требует роль `user` или `admin`).
3. **SEO & Dynamic Rendering:**
   - Хлебные крошки Schema.org `BreadcrumbList` в JSON-LD.
   - Микроразметка обсуждений `DiscussionForumPosting` для расширенных сниппетов Google и Яндекса.
4. **Автоматический сидинг:** при первом старте база наполняется 10 тематическими разделами и дискуссиями.

## 💡 Использование как шаблона

Исходный код `pyferro-demo` доступен в репозитории фреймворка в папке `examples/pyferro-demo/`. Вы можете использовать его как готовую основу для создания собственных сервисов на базе PyFerro.
